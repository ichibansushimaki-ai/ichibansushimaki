Vegetales disponibles para Gohan y Sushi Burger

Estas opciones se comparten entre ambos productos. Gohan permite hasta 3 vegetales; Sushi Burger, hasta 2. Puedes activar o desactivar cada vegetal.

Proteínas disponibles para Gohan y Sushi Burger

El cliente debe elegir exactamente una proteína activa. Si una proteína se agota, desactívala aquí y dejará de aparecer en ambos productos y sus promociones semanales.

El arroz sushi viene incluido en Gohan. Gohan y Sushi Burger permiten elegir queso crema con o sin. El recargo adicional de cada proteína se configura aquí.
